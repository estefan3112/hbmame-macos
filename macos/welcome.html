HBMAME for macOS

Unofficial universal build of HBMAME (Apple Silicon and Intel), signed with a Developer ID and notarized by Apple.

What this installer does

  • Copies HBMAME.app into your Applications folder. An older HBMAME.app there is removed first.
  • Creates the folder ~/Library/Application Support/hbmame for your ROMs and settings, with ready-made hbmame.ini, horizont.ini and vertical.ini. Existing settings are never overwritten.

Why macOS asks for your password

macOS asks for an administrator password for every installer that writes into the Applications folder. That is all it is used for.

Nothing else is installed or changed: no background services, no login items, no system extensions, no changes to system settings, and no files anywhere else. Apart from macOS's own installation record, the installer touches only the two places above.

Check it yourself

  • File → Show Files (⌘I) in this installer lists every file it installs.
  • The two short install scripts are public: macos/preinstall and macos/postinstall at github.com/estefan3112/hbmame-macos.

Uninstall

Drag HBMAME.app to the Bin. To also remove your settings, delete ~/Library/Application Support/hbmame.
